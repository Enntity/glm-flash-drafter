1. Requirements

The tested path uses one 128 GB GB10 (for example one DGX Spark) per independent site with your own compatible captures. Recipe mode needs two local GPUs to generate and capture GLM-5.3-Flash data in TP2; its full-size multi-site path is still experimental. You need your own teacher files and training data.

Start with the site runbook for installation, disk and memory requirements. No invite yet? Request one with a hardware summary. Do not post credentials, invite links, machine addresses or data in the issue.
