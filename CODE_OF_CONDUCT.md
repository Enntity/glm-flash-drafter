# Code of Conduct

We want this to be a welcoming project for everyone. Be respectful and
constructive, assume good faith, and keep discussion on the work.

Not acceptable: harassment, personal attacks, discriminatory language,
sharing others' private information, and sustained disruption.

Maintainers may edit or remove contributions and comments that break these
rules, and may block people who repeatedly do. Report problems to the
maintainers by opening a private security advisory on the repository or by
contacting them directly; reports are handled confidentially.

This code is adapted in spirit from the Contributor Covenant
(https://www.contributor-covenant.org).
